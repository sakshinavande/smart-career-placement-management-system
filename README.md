# Smart Career & Placement Management System

## About the Project
A web-based application designed to help students prepare for career opportunities and help placement officers manage recruitment activities.

## Key Features
- Student registration and login
- Student profile management
- Company and recruiter dashboards
- Job posting and management
- Job eligibility checking
- Career readiness scoring
- Placement statistics

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Maven
- HTML, CSS, and JavaScript (if implemented)

## Database
MySQL database: `smart_career_db`

Create the database locally and configure your database credentials using your local application configuration.

## How to Run
1. Clone this repository.
2. Open the project in your Java IDE.
3. Configure your MySQL database.
4. Update the local database configuration.
5. Run the Spring Boot application.
6. Open `http://localhost:8080` in your browser.
